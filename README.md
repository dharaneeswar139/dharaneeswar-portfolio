## 🔄 Website Workflow

1. The user opens the portfolio website.
2. `index.html` loads the main website structure.
3. `style.css` applies the visual design and responsive layout.
4. `script.js` handles interactive features.
5. Users can navigate through different portfolio sections.
6. Project and coding profile links provide access to external resources.
